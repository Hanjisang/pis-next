# PIS-Next V2 领域重构文档

文档状态：第一阶段基线
文档版本：V2-0.1
创建日期：2026-08-08
设计原则：净室设计

## 1. 用途

本目录是 PIS-Next V2 Domain Reset 的独立设计基线。V2 以病理对象、患者安全、来源追溯、责任链、报告不可变和审计要求为业务依据，不把现有 P05 文档、任何旧 PIS、旧数据库或旧实现直接当作 V2 领域模型。

## 3. 第一阶段边界

本轮只完成 P00-P03 和后续设计入口，不实现业务代码、数据库迁移、API、页面或生产切换。V2 模块目录仅作为隔离边界占位，待 P04 及后续阶段获得准入后再实现。

## 4. 规则优先级

V2 总指令和根目录 `AGENTS.md` 高于旧文档中的冲突语义。若后续发现 V2 基线本身存在业务不确定性，必须标记为“待业务确认”，不得用旧实现或猜测补齐。
