## 1. 文件定位

本文件当前为候选识别基线。“候选对象”不等于最终实体、聚合根、数据库表或代码类。最终分类和聚合边界将在后续 P05 工作包中逐步确认。

每行依次表达：模型编号、规范术语/候选名称、对象分类与业务定义、稳定内部身份及业务编号或外部标识、直接来源与主要下游、责任与历史保护、P04/场景/Q 依据、医院配置边界、是否继续详细建模、后续阶段输入、当前成熟度。
