## 1. 文件定位

本文件保留 43 项历史对象基线，并追加本次病理类型覆盖受控修正形成的正式对象边界。“对象”不等于数据库表或代码类；稳定身份、聚合边界和历史保护以本文件及关联追溯矩阵为准。

每行依次表达：模型编号、规范术语/候选名称、对象分类与业务定义、稳定内部身份及业务编号或外部标识、直接来源与主要下游、责任与历史保护、P04/场景/Q 依据、医院配置边界、是否继续详细建模、后续阶段输入、当前成熟度。

### 8.1 医疗上下文

#### P05-OBJ-010 患者引用

- **规范术语/对象名称/分类**：患者引用；医疗上下文引用。
- **是否由 PIS 自主拥有**：外部上下文引用。
- **业务定义**：引用医院患者权威身份，不是 PIS 患者主档案、统一患者主索引或所有患者资料的权威来源。PIS 保存稳定本地引用身份、外部患者标识和来源系统，用于连接申请、病例和报告历史。
- **产生时点/稳定内部身份**：首次接收或建立可追溯患者上下文时产生；需要稳定本地引用身份，是。
- **业务编号/外部标识**：本地引用身份不等于业务编号；外部患者标识与来源系统必须分开保存。
- **直接来源/主要下游**：HIS、EMR、主索引或其他已确认来源；申请、病例、患者与就诊快照、报告版本。
- **生命周期责任主体**：外部患者主数据责任方负责权威身份；PIS 业务责任人负责引用绑定、冲突处置和纠错。
- **允许变化的当前信息/不可覆盖历史事实**：当前显示资料可按权威来源受控更新；原外部标识、来源、关联关系、合并/拆分、纠错原因、责任人和影响范围不可覆盖。
- **相邻对象边界**：不等于患者主数据、不等于就诊引用、不等于快照；患者合并或拆分不得改写历史报告上下文。
- **候选不变量**：外部标识不得替代本地身份；外部变化不得覆盖历史快照；错患者纠错保留原关系、新关系及影响范围。
- **医院配置边界**：权威来源、字段优先级、冲突分级、展示字段和纠错复核级别可配置；不在 P05 重定义患者主索引。

## 13. P05 最终候选处理结论

本节为 43 项候选对象的最终 P05 处理矩阵，覆盖 WP-03 至 WP-09。旧表中的“基线候选”等成熟度保留作为工作过程记录，本节结论优先。

统一身份编号规则：

1. 稳定内部身份不可变，不因业务编号、外部标识、文件标识或当前显示值变化而改变；
2. 外部系统标识必须携带来源系统或命名空间，不得替代本地身份；
3. 文件标识只标识文件或承载物，不替代业务对象、版本或材料身份；
4. 版本标识标识一次版本事实，不替代报告生命周期或来源对象身份；
5. 临时身份转正式身份时保留原临时关系、转化时点、人员和原因；
6. 改号、纠错和重新关联保留前值、后值、原因、人员、时间、复核和影响范围；
7. 已形成业务事实的正式编号不得复用；
8. 未形成业务事实的预占号可按医院规则释放，但必须保留预占、释放和原因历史；
9. “允许改号”只表示可通过受控纠错产生新的当前显示值，不表示可以改变原身份或覆盖历史；
10. 医院配置不得突破身份稳定、来源闭合、责任可识别和版本不可覆盖底线。

### 13.0 核心编号边界

- **病理号**归属于病理病例，是病例正式建立时生效的业务编号；预登记可以预占但必须区分预占和正式生效。病例拆分形成的新病例取得新病理号，合并时原病理号全部保留，作废病理号不得复用；唯一范围由医院配置，但不得突破历史保护。
- **标本显示编号**归属于标本，内部身份必须稳定；显示号可以按病理号、标本序号或医院规则生成。追加标本建立新的标本身份，来源纠错不得改写原历史关系。
- **蜡块号**归属于蜡块业务记录，在取材形成明确计划和编号时分配；蜡块号可以打印在组织盒标签上。物理包埋完成或同一物理蜡块返工均沿用原业务身份；形成新的可独立切片和追溯的蜡块，或由剩余组织补块时，建立新的身份和蜡块号；作废蜡块仍保留身份、编号和历史。
- **玻片号**必须区分计划玻片和实际玻片；标签打印不表示实际玻片形成。新制作物理玻片建立新实际玻片身份；同一物理玻片去色、重染等继续处理沿用原身份，重新制片建立新身份。
- **数字切片版本标识**归属于数字切片版本，来源可以是实际玻片或明确的外部数字材料；重扫形成新版本，同一文件重复传输按原版本识别；文件标识不等于数字切片版本身份。
- **报告标识**至少分离报告生命周期身份、报告版本身份、报告显示版本号、PDF 文件标识、模板版本标识和外部报告标识；任何一种标识都不得替代其他身份。

身份编号字段顺序：稳定内部身份；业务编号；外部系统标识；文件标识；版本标识；临时标识；预占编号；历史编号；是否允许改号；是否允许复用。

### 15.1 共享对象和身份补充规则

1. 病理病例（OBJ-002）代表可独立追溯的病理诊疗业务，不等同于单一病理类型；独立分子业务建立独立病例身份，附属分子检测至少建立独立检测任务身份。

3. 细胞蜡块不新增核心对象，复用蜡块业务记录（OBJ-004）的身份、编号、来源、返工、作废、归档和历史保护规则。
4. 分子材料选择、分装、消耗、剩余、提取物和外送派生材料按独立追溯条件建立稳定身份；不建立万能材料对象。
