## 1. 矩阵字段约定

本矩阵采用“目录字段＋处置模板＋逐入口映射”的规范化表达：

- `p07-exception-catalog.md` 逐项提供异常编号、名称、分类、适用病理类型、严重程度、患者安全、影响对象和聚合；
- 本文件的处置模板逐项提供触发条件、检测环节、主要流程、相关步骤/决策、影响范围、阻断范围、未受影响对象继续规则、自动重试、即时处置、业务裁决、核对依据、补偿/恢复、历史保护、报告影响、外部影响、通知、审计、质量升级、关闭条件及P08/P09/P10/P14/P25输入；
- 逐入口映射表将每个P06异常入口和P07异常编号绑定到一个处置模板及P06正式追溯段落。模板是该行继承的正式字段集合；不同严重度、责任、阻断或恢复方式不得共用不适用模板。

## 4. 关闭判定

异常关闭必须同时满足：受影响对象已核验、阻断范围已解除或受控关闭、未受影响对象继续规则已记录、补偿/恢复事实已形成、报告和外部影响已评估、通知和审计证据完整、质量升级结论已记录、业务责任人已签收。任何关键身份或来源未确认时不得关闭为“已恢复”。
