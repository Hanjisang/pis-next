# P07 患者安全关键异常

文档状态：已完成
文档版本：0.1
创建日期：2026-08-06
本文件集中列出全部26项 `P07-SEV-1` 异常。

## 1. 统一安全处置底线

患者安全关键异常发生时：

- 立即阻断直接受影响的申请、病例、标本、蜡块、玻片、数字切片、制备物、分子任务、结果或报告输入；
- 隔离具体对象和其直接下游，不无依据停止无关病例、无关材料或同批已核验样本；
- 由病例责任人、材料责任人、医学责任人或报告责任人按异常类型裁决；系统管理员和服务身份不得替代业务裁决；
- 必须评估报告撤回、更正、重新签发、临床通知、外部回传暂停和质量事件；
- 保留原身份、来源、执行、结果、诊断、报告版本、外部事件、责任和审计证据；
- 只有身份/来源/版本核对、影响评估、纠正或新版本、通知、质量结论和授权开放均完成时才能恢复。

## 3. 关键异常的共同后续输入

所有P07-SEV-1异常均向P08输出受影响对象和开放方向，向P09输出患者安全、身份和报告保护需求，向P10输出隔离/补偿/一致性问题，向P14输出授权和强认证要求，向P25输出阻断、通知、恢复和证据测试条件。具体实现留待后续阶段。
