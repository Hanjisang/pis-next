## 1. 文档目的

本文只记录：

- 场景编号；
- 场景名称；
- 主要分类；
- 主要参与者；
- 业务目标；
- 后续详细设计批次。

本文不记录：

- 详细步骤；
- 完整异常处理；
- 状态机；
- 数据库；
- API；
- 页面。
