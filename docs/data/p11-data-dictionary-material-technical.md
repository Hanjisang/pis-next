## 2. 材料字段属性

1. `quantity_value`、`selected_quantity`、`remaining_quantity`和`consumed_quantity`必须同时带有`quantity_unit_code`；不在P11硬编码单位精度。
2. `source_material_id`、`derived_material_id`、`source_block_id`、`source_cytology_preparation_id`和`source_external_material_id`必须按材料类型检查其合法来源。
3. 细胞学记录、稳定制备物和实际玻片分开；直接涂片只产生P11-TBL-027和实际玻片关系，不强制P11-TBL-028。
4. 分子原始结果、质控、有效结果和医学判读不共享同一个结果列；每个阶段均有独立身份、版本和责任。
5. 组织蜡块、细胞蜡块和冰冻冰剩均使用来源关系，不假设所有病理类型经过同一路径。
