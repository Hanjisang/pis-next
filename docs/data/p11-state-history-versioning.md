## 1. 统一状态持久化规则

P08的当前状态保存在有边界的六类当前状态表中：临床对象使用P11-TBL-064，材料对象使用P11-TBL-065，任务对象使用P11-TBL-066，报告对象使用P11-TBL-067，集成对象使用P11-TBL-068，治理对象使用P11-TBL-069。它们不是一个无边界的万能状态表；每行必须带有对应的P08状态机代码和对象类型。

每次合法或被拒绝的状态转换均写入P11-TBL-070。历史行记录源状态、目标状态、转换事件、操作者、责任人、发生时间、原因、异常、授权和纠错关系。当前状态更新和历史写入位于同一责任模块事务边界；跨模块状态只通过P10事件和受控投影推进。

## 3. 状态、转换和禁止规则覆盖

- 124个P08正式状态全部作为受控`*_state_code`值保存；本文件不重新编号、不改写、不增加状态。
- 93个P08正式状态转换全部由P11-TBL-070记录；每行必须引用对应P08-SM代码和转换事件。
- 31组P08禁止转换通过当前状态+目标状态+状态机代码的事务检查、并发版本和授权守卫落实；拒绝结果写入审计和必要的异常事实，不写入非法当前状态。
- P11-TBL-064至069不是跨对象万能状态表，而是按临床、材料、任务、报告、集成和治理边界分开的当前状态能力；每个对象仍由所属模块负责写入。

## 4. 报告、诊断和结果版本

### 报告版本

报告生命周期保存在P11-TBL-011；报告版本保存在P11-TBL-057；版本组成引用保存在P11-TBL-058；PDF版本保存在P11-TBL-063；报告当前有效关系只由报告生命周期事务改变。版本具有版本类型、前序版本、替代版本、撤回关系、签发人、签发时间和不可变摘要。

### 诊断记录和医学判读

诊断记录版本P11-TBL-056和分子判读版本P11-TBL-060均为追加事实。新依据到达时形成新记录或新确认事实，保留原始责任、时间、依据引用和被取代关系；不能直接覆盖已确认意见。

### 原始检测结果

P11-TBL-036只保存设备原始结果及原始载荷引用；P11-TBL-037保存质控；P11-TBL-059保存有效结果；P11-TBL-060保存医学判读。复测、补测和无效结果均生成新事实或新版本，不能覆盖原始结果。

### 历史编号和受控纠错

业务编号变化写入P11-TBL-049受控纠错和相应历史事实；内部稳定主键不改变；旧编号不复用；编号生效范围、原因、审批、执行和影响均可追溯。

## 5. 并发、恢复和归档

当前状态表和可变聚合根使用ConcurrencyVersion；状态转换和版本事实使用追加序列。恢复操作先进入隔离状态，完成业务、文件、版本和审计校验后才允许后续阶段决定重新开放；恢复本身不得制造重复申请、病例、材料、检测或报告事实。
