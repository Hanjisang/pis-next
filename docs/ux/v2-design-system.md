# V2 前端设计系统

## UX01-DS-01 设计令牌

全局令牌覆盖间距、圆角、字体、表格密度、表面、边框和状态语义。页面不得自行建立互不兼容的颜色与间距体系。

## UX01-DS-02 视觉原则

系统采用专业、克制、高信息密度的桌面生产风格。颜色只表达成功、警告、错误、当前责任和未完成；业务类型不使用彩虹色体系。

## UX01-DS-03 密度与分辨率

默认适度紧凑，并在顶部提供“紧凑 / 舒适”两种列表密度；两种模式共用行高令牌，不由页面各自实现。核心工作区以 1920×1080 和 1366×768 为验收分辨率；小屏保持关键上下文和固定操作可达。

## UX01-DS-04 反馈

成功与失败反馈在操作上下文内持续显示。长操作禁用重复提交并显示 loading 或骨架。空状态使用任务语言，不显示笼统的 `No Data`。

## UX01-DS-05 弹层

侧栏用于技术医嘱和全局查询等上下文补充；报告预览使用大面积专用层；复杂登记、取材和诊断不放入 Modal。

## UX01-DS-06 可访问性

交互元素有可访问名称，焦点轮廓可见，表格具有表头语义，反馈具有状态语义，状态文本与图形共同表达结果。
