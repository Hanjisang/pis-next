# V2 取材工作区

## UX01-GR-01 页面目标

一个病例的全部标本在同一页面处理，左侧切换标本，右侧维护当前标本描述和蜡块。

## UX01-GR-02 快速蜡块

蜡块编号自动建议，输入后按 Enter 即可创建；支持复制、作废和补打。创建操作不使用逐块弹窗。

## UX01-GR-03 身份

取材医生使用 DoctorIdentity，记录员使用当前认证用户。技术员代录时必须明确选择取材医生，不能注入自由文本医生名。

## UX01-GR-04 完成

完成取材前保存描述并由后端生成正式玻片。成功反馈显示生成玻片数量。冰冻上下文创建冰冻蜡块，常规上下文创建常规蜡块。
