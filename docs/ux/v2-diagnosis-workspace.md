# V2 诊断工作区

## UX01-DX-01 页面目标

医生从 Workbench 的诊断队列进入后，直接在同一主工作区完成阅片、诊断录入、技术医嘱、签审流转、报告预览和签发。主动搜索病例时先进入 Case Center，再按需进入诊断工作区。

## UX01-DX-02 布局

- 顶部紧凑病例条：来源返回、病例概览、病理号、患者、业务类型、当前工作、进度和当前可用操作。
- 左侧材料区：标本、蜡块和玻片；点击玻片立即切换中间 Viewer。
- 中间主区：数字切片 Viewer，是桌面端最大视觉区域；没有数字切片时保持布局并显示稳定空态。
- 右侧诊断区：结构化诊断、镜下所见、病理诊断和备注。
- 底部辅助区：临床信息、技术结果、历史病例、历史报告和签审记录，默认收起以保留阅片空间。
- 普通业务 Shell 不显示永久 Sidebar；诊断工作区不受内容最大宽度限制。

## UX01-DX-03 操作规则

按钮由后端 `availableActions` 决定，只显示当前阶段可执行的保存、提交复诊、提交审核、签发等操作。技术医嘱按需开立，技术结果在底部辅助区查看；关联结果可以定位到对应玻片。报告预览解析签发快照并以报告版式显示，不直接展示 JSON、UUID 或内部状态代码。

从 Workbench 进入时，路由携带原队列和返回位置。返回后恢复队列、筛选、排序、分页和滚动位置；“完成并下一例”只从原诊断队列选择下一病例。

## UX01-DX-04 责任语言

签审记录显示初诊、复诊、审核、医生、时间和状态。界面不显示内部责任对象、权限或投影术语。

## UX01-DX-05 错误反馈

签发受阻时说明具体业务原因及处理方式，例如尚有必须等待的技术医嘱或玻片未完成。并发冲突要求刷新后重试，不静默覆盖。
