# V2 诊断工作区

## UX01-DX-01 页面目标

医生从病例池进入后，在同一主工作区完成材料查看、诊断录入、技术医嘱、责任流转、报告预览和签发。

## UX01-DX-02 布局

- 顶部固定上下文：病理号、患者编号、业务类型、申请科室、当前责任和报告状态。
- 左侧上下文：申请、标本、蜡块、玻片、数字切片和历史病理。
- 中间主区：结构化诊断、镜下所见、病理诊断和备注。
- 右侧：责任链、技术医嘱、返回结果、报告历史和提醒。
- 底部固定操作：保存、技术医嘱、提交下一责任、预览、签发。

## UX01-DX-03 操作规则

按钮由后端 `availableActions` 决定。技术医嘱在工作区侧栏开立，返回结果在同一工作区显示。报告预览解析签发快照并以报告版式显示，不直接展示 JSON、UUID 或内部状态代码。

## UX01-DX-04 责任语言

责任节点显示初诊、复诊、审核、医生、时间和状态。用户选择下一位医生，系统维护责任链；界面不显示内部责任对象名称。

## UX01-DX-05 错误反馈

签发受阻时说明具体业务原因及处理方式，例如尚有必须等待的技术医嘱或玻片未完成。并发冲突要求刷新后重试，不静默覆盖。
