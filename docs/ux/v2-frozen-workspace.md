# V2 冰冻工作区

## UX01-FR-01 页面目标

用户一眼看见当前轮次、每轮材料、玻片完成数、诊断/报告状态和下一步操作。

## UX01-FR-02 首轮

冰冻登记中录入的标本在开始第 1 轮时自动关联到该轮。首轮不要求再次手工登记相同标本。

## UX01-FR-03 新送检

当前轮未签发时，新标本加入当前轮；上一轮已签发时，按钮明确说明将创建下一轮，后端自动建立新轮次并关联新标本。

## UX01-FR-04 快速诊断

取材、制片、诊断和独立签发以步骤显示，但仍复用统一 V2 材料、诊断与报告对象。医生可凭诊断权限读取冰冻工作区，新增材料仍要求冰冻操作权限。

## UX01-FR-05 冰冻结束

所有轮次独立签发后允许结束。成功后显示新冰剩常规病理号，并可直接进入常规流程；重复结束返回同一常规病例。
