# V2 登记工作区

## UX01-REG-01 页面目标

登记员在单页核对患者/就诊引用、申请、业务类型和多个标本，提交后获得明确病理号并进入下一任务。

## UX01-REG-02 业务类型映射

已映射申请直接显示业务类型；映射失败时提示未识别并允许人工选择。本地合成环境允许选择预置业务类型进行验证，真实患者与申请字段由 Site Integration 的医院申请查询带入。

## UX01-REG-03 标本录入

标本采用页内列表，支持新增、复制、删除和排序。相近标本可复制上一项后修改，不为每个标本打开大型弹窗。

## UX01-REG-04 数据完整性

Core 当前只持久化患者引用和就诊引用，因此 UX01 不提供无法保存的患者姓名、性别、年龄和临床申请编辑框。医院接口接入后由只读申请上下文展示这些字段，避免造成已保存的错误认知。

## UX01-REG-05 结果反馈

成功后显示病理号、标本数和业务类型；下一步按业务类型进入冰冻、诊断或取材工作区。
