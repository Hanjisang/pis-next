# PIS V2 信息架构

文档状态：待业务确认
文档版本：PX03C
最后更新：2026-08-11
相关基线：PIS V2 PX03C Workbench → Case Center → Focused Workspace

## 1. 核心交互轴

PIS V2 只建立两个核心业务入口：

| 入口 | 关注对象 | 回答的问题 |
| --- | --- | --- |
| 工作台 | 人 | 我现在要处理什么？ |
| 病例中心 | 病例 | 这个病例现在是什么情况，以及围绕它还能做什么？ |

全局搜索是第三个全局能力，不是第三条业务轴：用户主动找到病例后，统一进入病例中心。

## 2. 一级导航

普通用户没有永久左侧业务导航。临床 Shell 只保留顶部 Toolbar、全局搜索（顶栏
Ctrl/Cmd + K）、用户入口和当前页面。用户头像菜单只显示个人入口和退出；具有管理员
权限时增加“管理后台”。管理员使用独立 Admin Shell + Sidebar，不能与临床 Shell 混用。

登记、取材、制片、冰冻、技术医嘱、诊断、报告、归档和质控不作为普通用户一级菜单，而是由工作台项目或病例中心当前操作进入。系统管理和配置从管理员头像入口进入，视觉上与业务 PIS 分离。

## 3. 工作台

工作台是高密度、队列优先的人的工作中心，按权限和数据范围显示：

- 我的工作：待初诊、待复诊、待审核、新技术结果、撤回待处理等；
- 生产来源队列：常规制片、细胞制片、冰冻制片、技术医嘱、待完成玻片、异常 / 返工；
- 待接诊病例；
- 我登记的病例。

跨病例联动只在工作台产生。工作项必须携带病例中心深链；点击工作项后，病例中心根据
focus 自动打开当前聚焦工作区，不再经过病例概览或要求用户再次点击“继续”。工作完成后
由当前工作台队列决定下一项，不按 caseId + 1 推断下一病例。

## 4. 病例中心

病例中心是单病例工作区，不是业务模块菜单。顶部固定病例上下文，至少持续显示：

- 病理号、患者、性别/年龄（当前数据没有时明确显示待补充）；
- 病理类型、来源科室、送检医生、登记时间；
- 当前环节、当前处理人、报告状态。

首屏通过病例摘要、材料摘要、生产摘要、诊断摘要、报告摘要和最近动态回答：谁、什么病例、为什么送检、有什么材料、做到哪里、谁在处理、报告是否签发。

病例级视图只保留概览、当前聚焦工作区和按需展开的病例辅助信息。材料树支持
Specimen → Block → Slide → DigitalSlide、细胞直接玻片以及外来材料的扩展表达，不强制
所有病例具备完整组织学层级。技术医嘱作为病例内摘要/面板，冰冻仅在存在 FrozenRound
时出现。

从搜索进入病例中心默认是紧凑 Overview；从工作台进入则直接进入以下聚焦工作区：

| 工作台任务 | 病例中心聚焦区 |
| --- | --- |
| 待取材 | Case Center / Grossing |
| 常规制片 | Case Center / Routine Production |
| 细胞制片 | Case Center / Cytology Production |
| 冰冻轮次 | Case Center / Frozen |
| 技术医嘱 | Case Center / TechnicalOrder |
| 待初诊/待复诊/待审核 | Case Center / Diagnosis |

聚焦工作区顶部固定病例条，保持返回、病理号、患者、病理类型和当前工作等最小上下文。
病例概览用于了解病例全貌，不把所有生产能力同时铺开。

## 5. 双向联动

| 来源 | 进入病例中心后的上下文 |
| --- | --- |
| 待登记/登记完成 | 登记或病例概览 |
| 待取材 | Case Center / Grossing |
| 常规制片 | Case Center / Routine Production |
| 细胞制片 | Case Center / Cytology Production |
| 冰冻轮次 | Case Center / Frozen |
| 技术医嘱/新技术结果 | Case Center / TechnicalOrder |
| 待初诊/待复诊/待审核 | Case Center / Diagnosis |
| 报告撤回/待签发 | Diagnosis 的报告辅助区 |
| 全局搜索 | Case Center Overview |

病例中心根据 `BusinessType`、病例事实、当前权限和可执行动作只显示有权操作。权限由后端授权决策和 `availableActions` 约束，前端不以 `roleCode` 代替授权。

## 6. 领域边界

本架构只新增查询投影、前端上下文和深链组合，不新增持久化 `Task`、`WorkItem`、`WorkflowInstance` 或 `StepInstance`。工作台待办由病例、标本、玻片、技术医嘱、诊断、报告和审计等业务事实重新投影。

脱水、包埋、切片、染色和封片保留为可选技术记录，不作为默认队列、病例生命周期或一级导航。

## 7. Focused Workspace 规则

1. Routine Production 首屏只展示病例摘要、Block / Slide 工作表、生成玻片、打印、扫码完成和完成并下一项。
2. Cytology Production 只展示 Specimen → Slide，默认不展示蜡块、脱水、包埋或组织学五阶段。
3. Frozen 以 FrozenRound 为工作单位，突出轮次、标本、等待时间、玻片和快速送诊。
4. TechnicalOrder 只展示当前医嘱、目标材料、项目、结果和完成动作。
5. 技术工作区不共用一个万能页面；允许共享 Case Shell、材料组件和玻片组件。
6. “完成并下一项/下一例”只能从当前 Workbench Queue 取下一项。

## 8. Diagnosis 视觉 Gate

Diagnosis 必须同时显示材料/玻片列、WSI Viewer 和诊断编辑列。Viewer 是桌面端最大视觉区域，
默认可见；点击带数字切片的玻片立即切换 Viewer。没有数字切片时保持 Viewer 尺寸并显示
“当前玻片暂无数字切片”，仍允许切换其他玻片。临床信息、技术结果、历史病例、历史报告和
签审记录放在底部辅助 Panel，默认不挤占阅片主舞台。

## 9. 假设与待确认

- 当前接口未提供性别和年龄时，界面显示“待补充”，不从旧系统或其他字段推断。
- “完成并下一项”沿用现有 Workbench 查询结果顺序；队列排序和并发更新规则仍以现有后端
  授权与投影为准。
- 以上两项均为待业务确认，不改变核心领域模型。

## 10. 验收基线

- 登记员登录后进入工作台，可从工作台进入登记；登记完成后的病例通过病例中心继续追踪；
- 普通业务用户在 Workbench、Case Center、Grossing、Production、Diagnosis 和 Report 页面
  不出现永久 Sidebar；
- 技术员可从工作台工作项直接进入对应的聚焦制片/技术医嘱区；
- 医生点击待诊断工作项后第一屏同时看到病理号、玻片列表、WSI Viewer、镜下所见和病理诊断；
- 全局搜索结果统一落到病例中心；
- 浏览器验收覆盖 1920×1080、1366×768、无 WSI 占位、玻片切换和队列下一项。
