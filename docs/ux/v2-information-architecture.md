# PIS V2 信息架构

## UX01-IA-01 一级导航

正式一级导航为：工作台、登记、取材、制片、诊断、冰冻、技术医嘱、报告、归档借阅、查询、质控统计、配置、系统管理。

导航由登录角色与权限共同过滤：

| 角色 | 默认任务入口 |
| --- | --- |
| 登记员 | 工作台、登记、冰冻、查询 |
| 技术员 | 工作台、取材、制片、冰冻、技术医嘱、归档借阅、查询 |
| 病理医生 | 工作台、诊断、冰冻、报告、查询、质控统计 |
| 管理员 | 全部获授权入口 |

## UX01-IA-02 路由

正式任务路由：

- `/v2/registration`
- `/v2/grossing/:caseId`
- `/v2/production`
- `/v2/diagnosis/:caseId`
- `/v2/frozen/:caseId`
- `/v2/technical-orders`
- `/v2/material-custody`

蜡块、责任链和技术医嘱目标不作为一级用户路由。

## UX01-IA-03 工作台

首页回答“今天我需要处理什么”，按角色展示登记、制片、诊断责任、技术结果和冰冻提醒。入口卡只表示真实待办或明确的查看入口，不复制完整菜单。

## UX01-IA-04 全局查询

任意页面按 `Ctrl+K` 打开查询侧栏。结果按病例、患者、材料、医嘱和报告分组，优先落到病例、诊断、材料或报告上下文。

## UX01-IA-05 配置中心

配置按业务配置、诊断配置、生产配置、组织权限、质控与报表分组。医院差异继续由 Profile、配置和适配器承担，不进入核心领域。
