# V2 制片工作区

## UX01-PRD-01 页面目标

制片主对象是玻片。工作台只突出待制片、进行中、今日完成、打印状态和完成状态，不以物理工序状态链作为中心。

## UX01-PRD-02 队列

列表保留病理号/患者、玻片号、染色/项目、来源、状态和操作。支持按病例过滤，不展示无关领域字段。

## UX01-PRD-03 扫码

扫描玻片号并按 Enter 后完成玻片，保留持续反馈并自动聚焦输入框。未找到、已完成和作废均显示可继续处理的明确消息。

## UX01-PRD-04 批量与补打

当前列表可全选并批量完成。打印与补打是直接材料操作，不通过“重置打印状态”实现。

## UX01-PRD-05 细胞学

细胞学病例支持标本直接创建玻片，不要求伪造蜡块。
