## 2. 关键 UX 结果

1. Diagnosis Workspace 以诊断编辑器为视觉中心，病例上下文、材料、数字切片、分子结果、技术结果、责任链、报告预览和签发动作保持在同一主工作区。
2. 登记在单页维护患者/就诊、业务类型和多个标本，支持新增、复制、删除和排序；会诊允许零本院标本登记。
3. 取材按病例和标本切换，支持快速生成、复制和直接修改蜡块编号，主要动作固定可见。
4. 制片围绕玻片队列组织，支持扫码、批量完成、打印和补打，不展示物理流程状态大链条。
5. 冰冻以轮次时间线呈现；已签发轮次保持只读，新送检自动进入新轮次，结束后直接显示冰剩常规病例。
6. 独立分子病例不制造蜡块或玻片；结构化结果进入诊断工作区并使病例进入公共池。
7. 会诊由登记员登记外院材料并生成统一 V2 玻片，页面明确交接技术员完成；登记员不能越权完成玻片。
8. 全局查询结果按病例、患者和材料分组，主落点为“打开病例”，不再显示缺失的内部类型字段。
