## 4. 正式决策

### BD-P04-080：正式支持的病理业务类型和版本边界

原确认前状态：待业务确认。
影响场景：SCN-PIS-110、SCN-PIS-118，并交叉影响既有 SCN-PIS-033、SCN-PIS-060。
Q 编号：Q-SCN-PIS-110-01～Q-SCN-PIS-110-08；保留并继续追溯 Q-SCN-PIS-033-14、Q-SCN-PIS-060-27。
批内依赖：批次首项。

最终确认结论：

1. 正式产品业务模型覆盖常规组织病理、术中冰冻、妇科细胞病理、非妇科细胞病理、穿刺细胞病理、细胞蜡块、分子病理、外送检测以及组织/细胞/分子多模态综合诊断。
2. 全部类型共享患者、就诊、申请、病例关联、标本身份、责任、审计、报告生命周期、接口、质量、档案和恢复能力。
3. 各类型保留材料制备、检测、筛查、判读和质量控制边界，不强制统一为一条线性流程。
4. 医院未启用某类型时只关闭入口或能力配置，不从正式领域模型删除该类型、核心历史或关联规则。
5. 产品可以分阶段交付，但正式产品范围和领域模型必须承载全部类型；细胞病理和分子病理均属于当前正式范围，不作为单纯后续扩展。

医院配置：启用入口、编号展示、模块能力和分阶段交付计划可配置；共享身份、来源、责任、审计、历史保护和报告版本底线不可配置。

确认状态：已确认。

### BD-P04-081：病理病例共享与独立检测模式

原确认前状态：待业务确认。
影响场景：SCN-PIS-110、SCN-PIS-118、SCN-PIS-121。
Q 编号：Q-SCN-PIS-110-05～Q-SCN-PIS-110-08、Q-SCN-PIS-118-01～Q-SCN-PIS-118-08。
批内依赖：依赖 BD-P04-080；为 BD-P04-087、BD-P04-088 的前提。

最终确认结论：

1. 病理病例代表一次可独立追溯的病理诊疗业务，不等同于单一病理类型。
2. 支持分子检测作为组织或细胞病例附属检测、独立建立病理病例，以及多个相关病例或检测业务通过稳定关系形成多模态诊断关联。
3. 附属分子检测必须有独立稳定的检测任务身份和结果身份，但不强制新建病理病例。
4. 独立申请、独立诊断、独立签发或医院制度要求独立归档的分子检测建立独立病理病例。
5. 独立分子病例必须有独立病例身份和独立业务编号；专用编号段或统一病理号体系由医院配置。
6. 附属检测可以继承上级病例展示上下文，但不得只以病理号作为唯一身份。
7. 同一申请下组织、细胞和分子业务是否共享展示编号由医院编号规则决定；内部身份、检测身份和报告版本身份始终分离。
8. 病例总状态不得覆盖不同病理类型、标本、检测任务和报告的独立事实。

确认状态：已确认。

### BD-P04-082：细胞学标本与病例分类

原确认前状态：待业务确认。
影响场景：SCN-PIS-110、SCN-PIS-111。
Q 编号：Q-SCN-PIS-110-02～Q-SCN-PIS-110-04、Q-SCN-PIS-111-01～Q-SCN-PIS-111-08。
批内依赖：依赖 BD-P04-080；为 BD-P04-083、BD-P04-084 的前提。

最终确认结论：

1. 组织、细胞、血液、体液、穿刺材料和外院材料复用统一标本核心对象。
2. 标本差异通过业务类型、来源类型、采集部位、采集方式和材料形态表达，不拆成互不兼容的标本实体。
3. 妇科、非妇科和穿刺细胞病理可以形成不同病例类型、流程和报告模板，但复用统一病例模型。
4. 妇科细胞学允许配置为独立病例类型和编号段，但不是全局强制规则。
5. 穿刺材料必须具有独立标本身份；专用显示编号或前缀由医院配置，不强制建立不同核心编号体系。
6. 标本接收、交接、来源、数量差异、异常和历史保护原则适用于全部标本类型。

确认状态：已确认。

### BD-P04-083：细胞学制备物与实际玻片来源

原确认前状态：待业务确认。
影响场景：SCN-PIS-112、SCN-PIS-113、SCN-PIS-119。
Q 编号：Q-SCN-PIS-112-01～Q-SCN-PIS-112-08、Q-SCN-PIS-113-01～Q-SCN-PIS-113-08。
批内依赖：依赖 BD-P04-082；为 BD-P04-084、BD-P04-088 的材料来源前提；与既有 Q-SCN-PIS-033-14 交叉追溯。

最终确认结论：

1. 每次直接涂片、液基制片、离心制片、沉渣制片或其他制备形成细胞学制备记录。
2. 只有中间材料需要保存、转移、重复使用、分装或作为后续材料来源时，才建立具有稳定身份的细胞学制备物。
3. 直接涂片可以由细胞学标本、制备记录和实际玻片直接构成来源链，不虚构不存在的中间制备物。
4. 液基悬液、离心沉渣和可保存细胞沉淀在需要重复制片、细胞蜡块或分子检测时，保留稳定身份、剩余量、消耗和保存关系。
5. 实际玻片合法来源包括蜡块业务记录、原始细胞学标本、细胞学制备物、外部材料和外院玻片。
6. 实际玻片始终具有稳定内部身份，计划玻片、打印标签和实际玻片分离；标签补打产生新打印版本。
7. 外院玻片经本地身份建立、患者和来源核对、文件或实物质量确认后，可以作为正式诊断依据，并保留外院标识。

确认状态：已确认。

2. 初筛、复核和最终诊断分别记录人员、角色、时间、依据和结果，不用最终诊断覆盖前序事实。
3. 充分性评价是独立业务事实，可以关联标本、制备记录、实际玻片和穿刺现场快速评价材料。
4. 初筛人员必须具备医院认可的培训、岗位资格或明确授权；普通系统角色不自动取得筛查资格。

6. 同一人员承担多个角色时分别形成责任确认，并遵守医院职责分离规则。

### BD-P04-086：HPV 等关联检测与细胞学病例关系

原确认前状态：待业务确认。
影响场景：SCN-PIS-116、SCN-PIS-117。
Q 编号：Q-SCN-PIS-116-01～Q-SCN-PIS-116-08、Q-SCN-PIS-117-05～Q-SCN-PIS-117-08。
批内依赖：依赖 BD-P04-080、BD-P04-081；为外部结果和综合报告引用前提。

最终确认结论：

1. HPV 及其他关联检测是独立检测业务事实，不作为细胞学报告的普通可编辑字段。
2. 支持独立申请、独立检测、独立报告、与细胞学病例关联、联合筛查及本地或外部实验室完成。
3. 检测结果、检测判读和细胞学诊断分别留痕；是否在同一综合报告中展示由医院业务模式和模板决定。
4. 细胞学报告签发后返回的 HPV 结果不得直接修改既有报告，必须进入补充、更正、重新签发或新综合报告流程。
5. 外部结果经来源、患者、标本、方法、完整性、资质和报告有效性核验后，才可作为本地医学依据。
6. 同一报告展示不等于同一业务对象；检测任务、结果身份和验证责任独立保留。

确认状态：已确认。

### BD-P04-087：分子检测的独立、附属和并存模式

原确认前状态：待业务确认。
影响场景：SCN-PIS-118、SCN-PIS-121。
Q 编号：Q-SCN-PIS-118-01～Q-SCN-PIS-118-08、Q-SCN-PIS-121-01～Q-SCN-PIS-121-08。
批内依赖：依赖 BD-P04-080、BD-P04-081、BD-P04-086；为 BD-P04-088～091 的前提。

最终确认结论：

1. 同时支持独立分子病例、组织病例附属分子检测、细胞病例附属分子检测和多模态综合诊断。
2. 一个病例允许多个分子检测任务；每个任务有独立身份、材料、方法、运行、结果、判读和责任记录。
3. 独立分子病例有独立病例身份和业务编号；附属检测有独立任务编号或稳定业务身份，不强制另发病理号。
4. 组织、细胞和分子报告通过固定引用和组成关系关联，不用复制文本替代正式关联。
5. 综合报告是新的正式报告版本或独立报告生命周期，不覆盖组成报告、原始结果或既有诊断记录。

### BD-P04-090：无效、失败、复测、补测和报告关系

原确认前状态：待业务确认。
影响场景：SCN-PIS-121、SCN-PIS-122。
Q 编号：Q-SCN-PIS-121-05～Q-SCN-PIS-121-08、Q-SCN-PIS-122-01～Q-SCN-PIS-122-08。
批内依赖：依赖 BD-P04-087、BD-P04-088、BD-P04-089；承接既有报告版本决策 BD-P04-047/048/049。

最终确认结论：
