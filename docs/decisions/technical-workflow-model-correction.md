## 1. 修订背景

PIS 的技术流程设计必须服务于实验室人员的实际操作，同时保证物料来源链和操作责任链完整。真实物理流程不应被机械转换为同等数量的系统对象、页面、状态或人工点击。

## 2. 本次修订结论

正式采用轻量技术流程原则：

```text
物料来源链＋操作责任链
```

系统重点记录新物料、责任转移、关键阶段完成、异常风险和医疗业务结果；不满足这些条件的物理动作不作为默认强制系统节点。

## 3. 受影响的首批决策

### BD-P04-020

原“组织盒独立核心身份”结论进入待修订状态。组织盒默认作为蜡块在取材、脱水阶段的物理承载信息，不作为强制核心对象；逐盒物流和自动化追踪作为医院扩展能力评估。

此前已确认的组织盒与蜡块概念区分、蜡块号可在取材阶段预分配、标签打印不等于物理蜡块形成等业务事实保留为历史记录，但当前不作为未经术语和场景修订的 P05 领域模型输入。

### BD-P04-025

推荐方向改为“蜡块业务记录贯穿技术流程，包埋采用轻量完成记录”。默认不建立独立包埋活动对象或物理蜡块版本；重包埋在原蜡块下增加操作记录，只有拆分形成多个可独立切片的蜡块时才新增蜡块记录。该方向仍待业务确认。

### BD-P04-026

后续重点确认蜡块稳定身份、蜡块号、来源标本、取材信息、脱水和包埋操作记录，以及拆分和补块关系，不再优先讨论复杂的组织盒与物理蜡块对象映射。当前暂停确认。

### BD-P04-027

后续重点确认玻片独立身份、玻片号、来源蜡块、切片类型、制片人员和时间、标签预打印、实际玻片形成、作废、补切、重切、深切及诊断/扫描使用关系。当前暂停确认。
