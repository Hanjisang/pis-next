# P12 命令API契约

文档状态：P12已基线化
正式命令：42项，编号为P12-API-001至042。每项均表达业务意图、目标聚合、守卫、幂等、版本、责任、事实、事件、错误、审计和负向验收；不得用通用更新能力替代。

## 1. 命令共同响应

成功响应至少包含：operation_identity、correlation_identity、business_fact_references、subject_identity、business_version、event_references、audit_reference、processing_state_code和safe_retry_code。失败响应使用`P12-SCH-017`并包含稳定错误、当前/预期版本（适用时）、处理方向、患者安全等级和审计引用。

## 3. 失败、重试和事务

所有命令均映射到P10事务或受控治理边界。聚合内命令在本地强一致边界内完成事实、守卫、并发和必要审计；跨模块命令通过事件、协调任务或对账；外部失败不回滚本地事实。可安全重试仅适用于契约校验修复后的技术失败或同载荷幂等重放；业务冲突、患者安全阻断、报告版本冲突和销毁/恢复失败必须人工处置。
