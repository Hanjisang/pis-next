## 2. 协议和标准状态

| 项目 | 实际状态 | P12处理 |
|---|---|---|
| 内部API风格 | 未确认 | 逻辑应用能力契约，不绑定HTTP/RPC |
| 医院传输协议 | 未确认 | 规范化语义、适配器配置模板和技术/业务结果分层 |
| 事件传输协议 | 未确认 | 21个产品中立事件契约，不生成AsyncAPI |
| 文件传输方式 | 未确认 | 登记、传输、校验、访问、归档、隔离和恢复语义，不决定FTP、共享目录或对象存储 |
| 行业标准 | 未确认 | 不虚构HL7、FHIR、DICOM或版本；接入时按适配器确认 |

## 3. 机器规范不生成说明

本批次缺少正式协议风格、版本、目标系统边界和安全传输决策，因此不生成OpenAPI或AsyncAPI。缺失项不阻塞P12，因为所有业务语义、字段、幂等、版本、错误、业务确认、安全、审计和追溯均在Markdown契约中完成；后续生成必须以本文件决策和契约正文为权威，并通过兼容性审查。
