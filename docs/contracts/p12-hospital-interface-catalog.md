## 1.1 适配器标准和失败影响补充

| 适配器 | 已有正式标准 | 主要失败影响 | 处理方向 |
|---|---|---|---|
| P10-ADP-001 | 未确认 | 无法形成可信认证或组织上下文 | 拒绝高风险业务，保留认证异常 |
| P10-ADP-002 | 未确认 | 患者/就诊/申请映射延迟或报告回传受阻 | 本地事实保留，进入重试和对账 |
| P10-ADP-003 | 未确认 | 申请原始事实无法自动接收 | 保留原文，进入人工补录或重放 |
| P10-ADP-004 | 未确认 | 医嘱/收费关联待核验 | 不阻断已有医学事实，形成关联差异 |
| P10-ADP-005 | 未确认 | 外部结果待接收或待核验 | 不形成本地运行/有效结果，隔离待核验 |
| P10-ADP-006 | 未确认 | 报告或文件调阅受阻 | 不改变报告版本，记录访问失败 |
| P10-ADP-007 | 未确认 | 扫描、数字切片或质量回执受阻 | 数字路径隔离，实体路径可继续 |
| P10-ADP-008 | 未确认 | 制片/染色执行回执缺失 | 技术任务受阻，材料来源和尝试保留 |
| P10-ADP-009 | 未确认 | 分子设备运行或原始载荷缺失 | 任务受阻，原始结果不伪造 |
| P10-ADP-010 | 未确认 | 外送交接或外部报告延迟 | 材料责任和外部事实保留，进入对账 |
| P10-ADP-011 | 未确认 | 文件保存、读取或校验失败 | 文件隔离，报告/业务事实不回滚 |
| P10-ADP-012 | 未确认 | 事件投递、回执或重试受阻 | 发件箱/投递状态保留，人工重放 |
| P10-ADP-013 | 未确认 | 指标、日志或告警缺失 | 形成观测异常，不修改业务事实 |
| P10-ADP-014 | 未确认 | 恢复批次或校验能力不可用 | 禁止生产放行，保留隔离和差异 |

## 3. 统一适配器映射边界

每个外部适配器必须完成身份、编码、状态、时间、版本、错误、原始消息、幂等、技术应答、业务确认、重试、补偿和对账映射。外部字段尚未确认时只提供规范化Schema和映射模板，外部字段列标记为“接入项目配置”，不把示例当作正式字段。
