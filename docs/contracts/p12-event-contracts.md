## 1. 统一事件Envelope

所有事件使用`P12-SCH-021`事件Envelope和`P12-SCH-022`事件关联：event_identity、event_type_code、event_version、occurred_at、recorded_at、producer_module_code、subject_identity、aggregate_identity、aggregate_version、correlation_identity、causation_identity、organization_context、sensitivity_code、payload_schema、replay_scope_code。事件生产事务提交后才产生可发布事件；事件不可变，错误通过新事件或治理事实表达。

## 3. 事件消费和失败

消费者使用event_identity、producer_module_code、aggregate_version和payload_digest去重；不依赖事件到达顺序改变聚合内即时不变量。重复、乱序、迟到、受阻和外部确认缺失均进入可靠任务、对账或人工关闭，不删除生产方事实。事件生产和消费均引用`P12-SCH-017`错误模型，事件Envelope本身不承载数据库表名、内部外键或机器地址。
