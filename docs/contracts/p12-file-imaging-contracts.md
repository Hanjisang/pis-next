# P12 文件、报告和数字切片契约

文档状态：P12已基线化
正式文件能力：6项；适用对象包括报告PDF、数字切片、外部报告文件、证据附件和恢复校验文件。未决定FTP、SFTP、共享目录、对象存储、预签名URL、HTTP直传、数据库BLOB或DICOMweb。

## 2. 报告PDF契约

- PDF生成、传输或访问失败不回滚报告签发事实；
- PDF必须绑定具体`report_version_identity`和`report_version_number`；
- 重新生成形成新的文件身份或文件版本，保留旧文件证据；
- PDF只承担呈现，不是唯一医学事实；结构化报告和医学正文由报告版本承担；
- 外部回传固定引用报告版本和文件版本；撤回时形成独立出站事件和对账记录。

## 3. 数字切片契约

数字切片必须引用实际玻片身份、扫描任务、数字切片版本和文件版本。扫描任务、传输完成、文件完整性、图像质量、诊断可用性和被诊断引用后的版本保护分别表达。重扫形成新尝试和新数字版本；重传不能静默替换已被诊断引用的版本；失败只隔离数字路径，实体玻片和不依赖数字材料的诊断路径可以继续。

## 4. 外部报告文件契约

外部报告文件必须保存外部机构、外部报告版本、来源消息、文件身份、摘要、来源验证、本地核验、业务引用和访问审计。外部文件即使完整可打开，也不能直接成为本地有效检测结果或本地医学判读；本地责任人必须完成核验或明确仅作为外部医学依据。

## 5. 传输边界

本批次只定义登记、初始化、内容传输、完成、摘要校验、格式校验、可打开性、图像质量、访问、归档、隔离、销毁和恢复语义。实际传输协议、存储产品、分段/续传机制、下载方式、有效期数值和容量数值留给后续正式技术决策；所有参数引用P09-PARAM-003、010、014、016–018，不填虚假数值。
