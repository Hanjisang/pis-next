# P14 资源、动作与范围模型

文档状态：P14 已设计

## 1. 授权三元组

授权对象由 `主体 + 动作 + 资源` 组成，并叠加组织、数据、任务、状态、版本、风险和审计条件。动作使用 P14 权限目录中的业务语义，不使用通用表/字段权限替代业务判断。

动作族包括：定位/读取、提交/建立、接收/签收、分配/接管、技术执行、医学确认、纠错、更正、签发、批准、复核、撤回、销毁、恢复、文件引用、导出、重试、重放、补偿和配置发布。

## 2. 正式数据范围

| 编号 | 范围维度 | 判断内容 |
|---|---|---|
| P14-SCOPE-001 | 医院范围 | 主体所属医院与对象归属医院 |
| P14-SCOPE-002 | 院区范围 | 主体可承担的院区或物理业务位置 |
| P14-SCOPE-003 | 科室范围 | 组织关系、责任科室和对象责任科室 |
| P14-SCOPE-004 | 工作组范围 | 技术组、诊断组、质量组或接口组 |
| P14-SCOPE-005 | 队列/任务范围 | 当前任务、队列和责任节点 |
| P14-SCOPE-006 | 病理类型范围 | 组织、冰冻、细胞、分子、外送、多模态等 |
| P14-SCOPE-007 | 病例/对象范围 | 指定病例、标本、材料、报告、文件或治理对象 |
| P14-SCOPE-008 | 来源/机构范围 | 外部机构、来源标识和接口目标 |
| P14-SCOPE-009 | 时间范围 | 业务事实时间、授权生效/失效时间和查询窗口 |
| P14-SCOPE-010 | 敏感度/用途范围 | 医疗正文、原始载荷、文件、审计证据、导出用途 |

## 3. 范围求交规则

有效范围是主体范围、角色范围、任务范围、代理范围、组织范围、对象范围和用途范围的交集；任一维度为空或冲突即拒绝。查询可以返回摘要，但不能因为摘要权限而自动获得原始医疗正文、原始载荷、文件下载或审计导出权限。

范围扩展必须是独立的授权事实，包含申请原因、批准人、有效期和影响对象；不能通过变更菜单可见性、队列过滤器或调用方参数扩大范围。

## 4. 对象与聚合覆盖

P14 继承 P11 的 63 个对象和 18 个聚合，不重新命名、不合并身份：

| 覆盖组 | 对象范围 | 授权焦点 |
|---|---|---|
| 身份与来源 | OBJ-001–OBJ-014 | 申请、病例、患者/就诊引用、外部标识和来源 |
| 技术与数字材料 | OBJ-015–OBJ-024 | 医嘱、执行、计划/实际玻片、扫描、冰冻和批次 |
| 责任、治理和文件 | OBJ-025–OBJ-043 | 责任、交接、异常、质量、纠错、审计、投递、销毁、恢复、模板和目标 |
| 细胞病理 | OBJ-044–OBJ-050 | 制备、充分性、筛查和复核责任 |
| 分子病理 | OBJ-051–OBJ-059 | 任务、运行、原始结果、质控、有效结果、判读和材料派生 |
| 外送与多模态 | OBJ-060–OBJ-063 | 外送记录、外部结果、多模态关联和外部材料核验 |

聚合范围为 `P05-AGG-001` 至 `P05-AGG-018`：病理申请、病理病例、标本、蜡块、实际玻片、数字材料、技术医嘱、术中冰冻、诊断责任、诊断记录、报告生命周期、出站事件、细胞制备与材料、细胞筛查与复核、分子检测任务与运行、分子材料与分析物、外送检测与外部结果、多模态诊断关联。聚合内部权限不能跨越数据所有权边界。

## 5. 状态和版本守卫

所有 31 个 P08 状态机的动作必须核对当前状态、目标状态、来源事实、责任和预期版本。对于报告版本、原始结果、外部结果、诊断快照、数字切片和纠错事实，授权结果必须绑定版本；“允许修改”只能解释为形成新事实或新版本，不是覆盖历史。
