# P14 能力与权限目录

文档状态：P14 已设计

## 1. 目录口径

本目录把 P12 的 70 个内部正式 API 和 12 个医院接口映射为 82 个正式业务能力，并一对一建立 `P14-PERM-001` 至 `P14-PERM-082` 权限标识。权限是业务动作，不是数据库表操作；查询、文件引用、重放、补偿和治理动作均需独立授权。

能力和权限的正式总数：82；其中内部能力 70，医院/外部接口能力 12；内部命令 42、查询 18、文件能力 6、内部协调 4。

## 6. 统一权限语义

允许结果必须同时满足能力、权限、主体、资格、组织范围、数据范围、对象/状态、责任、并发、风险和审计条件。任何能力不得隐含全部对象、全部病理类型或全部数据范围；服务、设备、外部系统权限在 `p14-service-device-identities.md` 中进一步收窄。
