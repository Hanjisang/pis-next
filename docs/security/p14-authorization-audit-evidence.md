# P14 授权审计证据模型

文档状态：P14 已设计

## 1. 证据类型

授权审计证据共 13 类：

| 编号 | 证据类型 | 必要内容 |
|---|---|---|
| P14-AUD-001 | 认证上下文 | 主体、认证强度、时间、来源和结果 |
| P14-AUD-002 | 授权决策 | 输入摘要、命中规则、结果、原因和版本 |
| P14-AUD-003 | 业务操作审计 | 动作、对象、责任、前后业务引用和结果 |
| P14-AUD-004 | 代理使用 | 授权人、被代理人、实际操作者、范围和时间 |
| P14-AUD-005 | 临时授权使用 | 临时关系、有效期、动作和失效结论 |
| P14-AUD-006 | 紧急授权使用 | 风险原因、最小范围、强认证和事后任务 |
| P14-AUD-007 | 第二人复核 | 复核人、复核依据、结果、时间和冲突 |
| P14-AUD-008 | 服务调用 | 服务/任务身份、任务、载荷摘要和处理结果 |
| P14-AUD-009 | 设备提交 | 设备、批次、尝试、原始载荷和质量 |
| P14-AUD-010 | 外部接口交换 | 接口、外部系统、消息、版本、摘要和对账 |
| P14-AUD-011 | 权限/角色变更 | 请求、批准、生效范围、变更前后和原因 |
| P14-AUD-012 | 组织/数据范围变更 | 组织关系、对象/用途范围、起止和批准 |
| P14-AUD-013 | 拒绝、隔离和人工裁决 | 稳定错误、患者安全等级、影响和后续方向 |

## 2. 证据不可变性

审计由业务授权边界自动生成；主体或权限管理人员不能删除、重写或用新配置解释旧结论。权限、角色、范围或代理变更只能影响未来请求。审计查询和导出本身也生成 `P14-AUD-003` 与 `P14-AUD-011/012` 相关证据，并遵守最小数据范围。

## 3. 敏感信息

审计使用内部身份、外部标识摘要、对象引用、版本和影响范围来保证追溯；患者姓名、完整身份证件、完整原始报文、认证秘密和文件内容不得无必要进入日志。审计人员只能在具备用途、范围和导出批准时查看敏感正文或原始载荷。

## 4. 授权审计与业务事实分离

审计事件、异常记录、质量事件、诊断记录、材料记录、报告版本和接口投递记录各自保持边界。授权决策不能代替业务事实；业务事实也不能反向推断缺少的授权证据。高风险动作必须同时有业务事实、授权决策、责任、复核/批准和审计引用。
