# P14 组织与数据范围设计

文档状态：P14 已设计

## 1. 组织模型

授权组织上下文至少区分医院、院区、科室、工作组、岗位/角色、任务队列和外部机构。组织关系是主体与数据范围的输入，不等同于患者、病例或材料所有权。医院的具体组织编码、跨院区规则和外部机构目录待医院确认。

## 2. 数据范围分层

| 层级 | 可解决的问题 | 典型主体 | 保护要求 |
|---|---|---|---|
| 医院 | 租户隔离与跨医院访问 | 科室管理、审计 | 默认不跨医院 |
| 院区 | 物理材料和岗位所在位置 | 接收、技术、档案 | 仅按职责开放 |
| 科室 | 业务责任归属 | 病理登记、诊断、质量 | 不能代替医学资格 |
| 工作组 | 队列和协作关系 | 技术组、诊断组、接口组 | 只覆盖当前职责 |
| 队列/任务 | 当前待办和责任 | 接收、筛查、复核、分子 | 接管后责任可审计 |
| 病例/对象 | 精确到病例、标本、材料、报告或文件 | 纠错、签发、借阅 | 高风险必须对象级 |
| 来源/外部机构 | 外部材料与结果的来源隔离 | 外送协同、接口身份 | 不转成本地事实 |
| 时间/用途 | 查询窗口、临时授权、导出目的 | 审计、会诊、紧急 | 过期自动失效 |

## 3. 最小必要数据

查询授权必须区分摘要、医疗正文、原始载荷、数字切片、报告 PDF、审计证据和导出文件。主体只获得完成任务所需的最低数据粒度；跨病例统计、审计导出和文件下载需要单独用途与范围。患者和就诊引用使用 P11 外部上下文和快照规则，不能把查询权限变成患者主数据管理权。

## 4. 跨组织和外部数据

外部身份只能作用于 P12-HIF-001 至 P12-HIF-012 的目标和报文范围。外送机构只能接收已授权的材料和报告文件，外部结果必须保留来源、版本、机构和核验责任。跨院会诊或临时协作必须建立明确的对象、时间、用途和撤销范围。

## 5. 范围变更

组织、角色、工作组、队列和数据范围变更必须有申请、批准、生效时间、失效时间和审计。变更只影响新的授权决策；既有诊断、报告、材料、交接、外部结果和审计事实沿用当时的主体与范围快照。

## 6. 待确认项

- 医院、院区、科室、工作组和外部机构的正式编码；
- 具体岗位资格来源、资格有效期和跨院区兼岗规则；
- 敏感数据分级、导出审批层级和会诊的最小字段集；
- 外部机构可见的报告/文件范围和医院接口的组织映射。

这些待确认项不能降低 P14-RULE-002、007、010、014 和 022 的保护强度。
