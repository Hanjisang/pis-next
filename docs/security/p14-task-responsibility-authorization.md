# P14 任务责任授权模型

文档状态：P14 已设计

## 1. 责任不是角色的别名

角色表示主体可能承担的业务职责；任务责任表示主体对某个具体对象、队列或版本承担的当前责任。以下 6 类责任关系构成 P14 的正式任务责任类型：

| 编号 | 责任类型 | 形成方式 | 可支持的动作 |
|---|---|---|---|
| P14-TASK-001 | 分配责任 | 责任人被分配到任务 | 接受、接管前的查看和准备 |
| P14-TASK-002 | 接管责任 | 责任人确认接管 | 形成任务范围内的记录或执行事实 |
| P14-TASK-003 | 交接责任 | 原责任人交出、接收方签收 | 责任转移和后续动作 |
| P14-TASK-004 | 代理责任 | 有效代理关系覆盖当前任务 | 在代理范围内执行，保留双方身份 |
| P14-TASK-005 | 批准责任 | 独立批准人形成批准事实 | 高风险授权、销毁、恢复或版本动作 |
| P14-TASK-006 | 独立复核责任 | 独立复核人完成复核 | 复核、确认或关闭指定风险 |

## 2. 任务授权判定

任务动作必须同时满足：任务属于允许的病理类型；任务对象、状态和版本一致；主体具备对应角色和资格；主体属于任务组织/队列范围；主体已分配或接管责任；代理（如有）有效；高风险动作的批准与复核满足要求；动作产生审计证据。仅能查询任务不等于能提交或确认任务。

## 3. 责任转移

责任转移必须是新事实，至少记录交出方、接收方、实际操作者、对象/任务、原因、时间、版本和签收结果。交接失败、接收方不具备资格或对象被隔离时，不得让新主体自动获得责任；原责任和失败事实保留。

## 4. 病理责任边界

- 标本接收责任不等于取材责任；
- 技术执行责任不等于医学判读责任；
- 设备运行责任不等于有效结果确认责任；
- 细胞筛查责任不等于细胞最终诊断责任；
- 外部结果接收责任不等于外部结果医学核验责任；
- 诊断记录责任不等于报告签发责任；
- 报告签发责任不等于报告受控撤回或重新签发的批准责任；
- 系统、接口和部署运维责任不等于任何医学责任。

## 5. 责任失效

主体停用、资格过期、组织关系结束、任务关闭、代理撤销、临时授权到期、对象进入阻断状态或版本发生冲突时，授权结论必须重新计算。已经形成的业务事实不因责任失效而删除；后续处理转为交接、补偿、复核或治理任务。
