# P14 职责分离模型

文档状态：P14 已设计

## 1. 正式职责分离规则

职责分离共定义 12 条正式规则。规则只针对 P02 角色原则、P06 流程、P08 状态机和 P12 高风险动作中已经存在的责任，不对普通查询和低风险准备动作过度拆分。

| 编号 | 不得由同一责任链无痕完成的组合 | 例外处理 |
|---|---|---|
| P14-SOD-001 | 诊断形成与最终独立复核 | 受控例外、原因、批准、复核 |
| P14-SOD-002 | 报告起草与报告签发 | 依据医院报告规则明确记录 |
| P14-SOD-003 | 身份/编号纠错申请与批准 | 影响评估和独立复核 |
| P14-SOD-004 | 报告更正/撤回/重签申请与批准 | 原版本、原因和影响留痕 |
| P14-SOD-005 | 材料销毁申请与批准 | 冻结检查和见证责任分离 |
| P14-SOD-006 | 恢复申请与生产重新开放批准 | 恢复校验人独立 |
| P14-SOD-007 | 权限/角色请求与权限批准 | 变更人和批准人分离 |
| P14-SOD-008 | 数据范围请求与范围批准 | 组织和用途证据分离 |
| P14-SOD-009 | 接口重放申请与接口审计确认 | 原始消息、影响和结果核对 |
| P14-SOD-010 | 质量整改执行与高等级质量事件关闭 | 责任、证据和关闭复核分离 |
| P14-SOD-011 | 紧急授权发起与事后复核 | 事后复核不得由发起人独立完成 |
| P14-SOD-012 | 服务/设备执行与人工医学确认 | 非人工来源不能替代人工责任 |

## 2. 判定规则

职责分离判断使用实际主体、责任关系、代理关系、批准关系和复核关系，而不是只比较账号或角色名。代理、临时授权和紧急授权不能消除已存在的分离要求；如果同一人工主体在不同角色之间切换，仍按同一责任链识别冲突。

## 3. 例外

医院规模不足或紧急事件需要例外时，必须记录无法分离的事实、患者安全影响、替代控制、批准人、有效期、第二次复核和关闭证据。例外不会转化为永久角色权限，也不能用于关闭审计或覆盖历史。
