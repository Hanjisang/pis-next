文档状态：P08 已设计
判定原则：分类是每个对象的主要建模结论；对象可同时被其他对象的转换引用，但不会因此获得万能状态。

## 1. 分类统计

| 主要结论 | 数量 |
|---|---:|
| 建立正式生命周期状态机 | 17 |
| 建立独立任务状态机 | 10 |
| 使用不可变事实模型 | 16 |
| 使用不可变版本或快照模型 | 5 |
| 只建立质量或可用性维度 | 7 |
| 使用派生展示状态 | 2 |
| 属于医院配置或不需要独立状态模型 | 6 |
| 合计 | 63 |
