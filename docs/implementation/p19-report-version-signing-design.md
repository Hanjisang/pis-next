# P19 报告版本与签发设计

报告草稿与诊断意见分离。报告内容版本使用结构化章节和完整快照字段，审核绑定明确版本而不是当前可变草稿。签发前应用层重新检查任务责任、版本、独立审核、技术医嘱阻断、数据范围和增强认证；成功后同一事务写入版本状态、签发事实、状态历史、审计和 outbox。

增强认证通过 `EnhancedAuthenticationPort`，local/test 使用服务端可信开发适配器并生成关联实际主体和操作的证明；非 local/test 在没有正式接入证明时拒绝。浏览器按钮、复选框、请求头或普通密码均不被当作证明。

同一内容版本的签发事实具有唯一约束，签后版本只读。报告内部 ID、业务编号和内容版本号分离；当前有效版本由报告聚合关系维护，不产生 PDF 或医院回传成功假象。
