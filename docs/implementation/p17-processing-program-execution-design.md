# P17 组织处理程序与执行设计

程序、版本、步骤和运行是不同事实。处理批次保存程序版本摘要，运行再次保存相同摘要，避免后续程序修改影响历史解释。P17 迁移只种子 `P17-SYNTHETIC-REFERENCE/SYNTHETIC-1`，仅允许 `local` 和 `test` 环境；正式环境必须等待经批准的正式程序版本。

执行模式有 `HUMAN` 和产品中立的 `DEVICE`。设备模式只保存设备身份、外部运行标识、消息 ID、负载摘要、原始载荷引用和发生时间，不实现任何厂商 SDK、协议或设备控制。

原始结果收到后进入 `p17_processing_raw_result`，不自动成为有效医疗结果。人工主体通过确认命令生成 `p17_processing_result`，明确结果状态、可否进入包埋和摘要。有效结果、审计和 outbox 均可追溯到运行、批次成员、计划蜡块和来源标本。

中断/失败先产生 P07 异常，再记录逐成员影响；恢复产生独立恢复事实；需重处理时新建任务并通过 `p17_processing_reprocess` 指向原批次、运行和成员。原始运行、结果和异常永不覆盖。
