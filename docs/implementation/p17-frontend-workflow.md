# P17 前端工作流

`P17TechnicalProcessingWorkbench.vue` 提供六段纵向工作流：输入计划蜡块 ID、加载处理/包埋队列、建立并接管任务、建立批次并加入成员、启动执行、接收原始事实、人工确认有效结果、完成批次、建立并接管包埋任务、开始包埋、记录要求和方向、确认实际蜡块形成。

前端不把按钮点击当作成功。每个命令等待后端权威响应，显示后端状态和并发版本；错误显示错误码和安全提示。命令键按对象和动作保持稳定，后端负责最终幂等和版本冲突判定。界面明确显示原始执行事实不等于有效业务结果、计划蜡块不等于实际形成蜡块。

本地演示只选择合成程序和合成数据。未实现后续阶段入口，未加入物理打印成功假设、真实设备控制或真实患者字段。
