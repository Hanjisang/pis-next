# P15 前端登记与接收工作流

前端提供一个中文工作台，覆盖四个受控动作：登记合成申请、建立病例、登记预计标本、扫码接收。页面不允许直接修改状态；所有动作通过后端业务命令完成。当前工作台只显示最小患者/就诊外部引用和病理业务上下文，不显示诊断、报告或真实患者数据。

交互顺序与 P06/P08 保持一致：

1. 登记页提交外部申请或手工申请；成功后显示申请内部引用、申请号和处理状态。
2. 建案页选择申请和病理类型，建立病例；成功后显示病理号和病例身份。
3. 预计标本页输入容器条码、材料类型、来源部位和预计数量；每个容器有独立卡片。
4. 接收台聚焦条码输入框，支持键盘扫描器回车提交；显示逐容器状态、接收时间、责任和异常方向。
5. 重复点击、重复回车或网络重试使用客户端请求键和后端幂等键，不重复形成接收事实。

前端使用 `npm.cmd` 兼容的标准脚本，TypeScript 严格模式，API 错误显示稳定错误码和安全重试提示。未授权、范围不匹配、版本冲突、身份不一致和数量差异均以阻断/隔离信息显示，不能通过隐藏按钮改变后端决策。
