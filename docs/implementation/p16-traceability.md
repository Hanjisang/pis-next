# P16 追溯矩阵

| 业务事实 | 必须追溯到 | 物理边界 |
|---|---|---|
| 取材批次 | 组织、标本、任务责任、开始/结束和审计 | 不承载下游处理 |
| 取材记录 | 病例、标本、批次、操作者、时间、核对摘要、版本 | 不覆盖旧事实 |
| 组织取样 | 取材记录、来源标本、部位、数量、计划蜡块 | 不等同物理蜡块 |
| 计划蜡块/包埋盒 | 来源标本、取样、批次、业务编号、版本 | P16不写物理形成 |
| 标签 | 目标身份/版本、快照、模板版本、条码、生成主体 | 生成不等于打印成功 |
| 打印请求/尝试 | 原标签、原因、操作者、时间、适配器结果 | 不确认未确认的物理打印 |
| 取材完成/交接 | 所有前置事实、责任和下游交接 | 仅交接给后续技术流程 |

孤儿检查标准：任何 P16 取样、计划蜡块、标签、打印尝试都必须能通过明确外键或业务引用回到 P15 标本和 P16 批次/记录；不允许只靠自由文本来源。
