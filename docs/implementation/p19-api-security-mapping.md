# P19 API、安全与授权映射

| 操作 | P12/P14 | 关键守卫 |
|---|---|---|
| 诊断任务、责任、初诊 | API-034 / PERM-034 | 任务责任、专业主体、范围、版本 |
| 诊断/报告队列 | API-053/055/057/058 / PERM-055/057/058 | 组织、数据、任务范围、最小字段 |
| 报告生成、审核、签发 | API-035 / PERM-035 | 诊断版本、独立审核、增强认证、签发前重校验 |
| 补充、更正、撤回、重签 | API-036 / PERM-036 | 原版本、原因、批准、增强认证、审计 |

现有 `P15AuthorizationService` 在应用层执行权限和 `P19-DIAGNOSIS-REPORT` 任务责任。管理员、服务身份、设备身份和共享账号不会自动取得医学责任。审计记录授权、责任、版本和结果；outbox 仅携带最小身份与摘要，不携带完整患者或报告正文。
