# P17 API、安全与责任映射

根路径为 `/api/p17`，控制器提供 29 个路由：2 个队列查询、3 个任务查询/建立/接管、处理批次建立/查询/程序/执行模式/成员/开始/步骤/中断/失败/完成共 11 个、原始结果和有效结果 2 个、影响/恢复/重处理 3 个、包埋任务建立/查询/接管/开始/要求/完成 6 个、实际蜡块查询/返工/作废 3 个。

| 动作 | 权限 | 责任/安全规则 | 关键错误 |
|---|---|---|---|
| 队列、任务、批次、运行 | `P14-PERM-050` | P17 任务范围、医院组织范围、责任人接管 | `P12-ERR-031/034/074/076/077` |
| 蜡块、包埋、实际形成 | `P14-PERM-014` | 来源蜡块、包埋责任、物理形成和作废校验 | `P12-ERR-032/036/074/077` |
| 原始设备事实 | `P14-PERM-029` | 仅产品中立身份/原始事实；消息 ID 与摘要幂等 | `P12-ERR-003/035/075` |
| 有效结果确认 | `P14-PERM-050` | `HUMAN_USER` 主体人工确认，设备/服务主体不得确认医疗结果 | `P12-ERR-075` |

所有写命令要求幂等键，实体更新要求预期并发版本；权限、组织范围、责任人和高风险作废均写审计。状态历史、业务事实和 outbox 在应用服务事务内共同提交。
