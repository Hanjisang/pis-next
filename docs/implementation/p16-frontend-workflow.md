# P16 前端取材工作流

P16 在现有 Vue 应用中增加取材工作台，保留 P15 登记/接收工作台。页面包含队列过滤、任务接管、条码/病例输入、大体描述、组织取样、计划蜡块/包埋盒、标签预览、参考打印提交、打印历史和完成前检查。

工作台必须：

- 支持扫描输入和 Enter 提交，自动聚焦，不在前端计算最终蜡块号；
- 显示接收状态、病例/标本最小核对摘要和高显著身份冲突提示；
- 使用后端权限结果控制可用操作，按钮隐藏不是安全边界；
- 对重复提交显示幂等结果，对版本冲突保留编辑内容并要求重新读取；
- 标签预览只展示冻结快照和版本，参考打印明确显示“已提交/未确认物理打印”；
- 完成前检查大体描述、取样去向、蜡块编号、标签生成和异常处理；
- 不出现脱水、包埋执行、切片、染色、诊断或报告页面。

前端测试覆盖队列、扫描、身份安全、接管、取样、计划分配、标签预览、提交/重打、幂等、版本冲突、授权和完成门禁。
