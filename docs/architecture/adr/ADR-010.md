# ADR-010：报告、文件和数字切片

状态：已决定
日期：2026-08-06
背景：P10需要在不改变P04–P09确认结论的前提下形成可追溯、可验证且不泄漏后续实现的系统架构。
架构驱动：P09-REQ-0021–0029、0050–0060、0097、P05-INV-056/070
候选方案：报告和PDF绑定提交；文件替代业务事实；扫描强制；数字版本可静默替换
决策：选择业务报告版本与文件能力分离；扫描可选；数字切片版本固定来源、文件和质量；综合报告固定组成版本。
理由：PDF或扫描平台可能不可用，医学事实和实体玻片路径必须保持可用；文件不可用不能抹除引用关系。
正面影响：报告签发不受PDF生成阻塞，数字材料质量可隔离，未来可替换文件能力。
负面影响：增加模块边界、协调记录、观测和治理能力；P11、P12、P14、P25和P27需要继续细化实现边界。
风险：PDF失败回滚报告、文件被替换后引用漂移、所有病例强制扫描。
缓解措施：以主责任模块、业务事件、幂等、审计、受控纠错、对账和关闭审查保护边界；所有未确认参数进入后续确认，不在P10硬编码。
适用边界：P05-INV-005/012/013/025/056/070；P10-MOD-008–010/015。
重新评估条件：文件规模、法规格式和数字病理能力变化时复评。
需求追溯：P10-RULE-012/017；P10-DRV-005/006
